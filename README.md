# Flink CDC Oracle to Doris

This project provides a solution for real-time data synchronization from Oracle databases to Apache Doris using Apache Flink CDC (Change Data Capture).

## Overview

Flink CDC Oracle to Doris enables real-time streaming of data changes from Oracle databases to Apache Doris, a high-performance analytical database. This solution leverages Apache Flink's CDC connectors to capture database changes and stream them efficiently to Doris.

## Features

- **Real-time Data Synchronization**: Capture and stream database changes in real-time
- **Oracle Source**: Support for Oracle database as the source system
- **Doris Sink**: Efficient data loading into Apache Doris
- **Scalable**: Built on Apache Flink for distributed processing
- **Change Data Capture**: Track inserts, updates, and deletes from Oracle

## Prerequisites

- Apache Flink
- Oracle Database
- Apache Doris
- Java Development Kit (JDK)
